# Material validation required before research acquisition

This is a plan, not a completed pilot. No participant observations, item familiarity norms or TOT yield estimates exist for this authored set. The software validation uses synthetic inputs only.

1. Recruit an independent sample of Mandarin speakers matching the intended population, with consent and a preregistered exclusion/adjudication policy. Record language background, dialect and input-method proficiency only when justified by the study.
2. Before using the experimental timing, obtain independent ratings of definition clarity, intended-word recognition familiarity, active retrieval familiarity and alternative valid answers. Do not present the same target before its TOT trial in the actual acquisition session.
3. Have at least two qualified Mandarin-speaking raters independently evaluate all proposed alternatives and pronunciations. Resolve disagreements without consulting experimental outcomes. Freeze accepted spellings, target pronunciation, character-count policy and material version before data collection.
4. Specifically review tot03 菖蒲 versus longer botanical synonyms; tot05 耄耋 versus generic high-age terms; tot06 司南 versus compass variants; and tot07 三棱镜 versus generic 棱镜. The supplied strict scorer may reject a plausible answer; raw and alternative-target text are retained so this does not disappear. Editorial specificity is not empirical uniqueness.
5. Pilot the complete fixed protocol to estimate know/TOT/don't-know/missing proportions, recognition-only confirmation, exact typed resolution, timeouts and input-method failures for each item. Check that character-count and initial-sound guesses are collected before a reported resolution. No minimum TOT yield is asserted here.
6. Revise or remove ambiguous/unfamiliar items using prespecified criteria; repeat independent material validation after changes. Do not combine versions without modeling the material change. Develop study-specific comparison distributions if needed; the current12-item descriptive summaries are not individual ability scores.

Mandarin initial convention: consonants b,p,m,f,d,t,n,l,g,k,h,j,q,x,zh,ch,sh,r,z,c,s, and0 for no consonant onset. y/w are pinyin spelling conventions and are not treated as consonant initials here. The participant must report the whole digraph zh/ch/sh rather than its first letter. Dialect-dependent realizations require a prospective policy. Character count is an orthographic metric; it is not an unqualified substitute for the original English syllable/stress analysis.

The source paper's effective-target category can include an independently recovered word different from the experimenter's target. The current automatic confirmation concerns the intended target only. A researcher reproducing the effective-target analysis must manually code the alternative word and rescore its partial features; do not count every subjective TOT or every alternative entry as a verified effective target.
