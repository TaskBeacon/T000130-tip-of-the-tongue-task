# Task Logic Audit

## 1. Paradigm Intent
T000130 Tip-of-the-Tongue Elicitation Task; lexical retrieval failure and preserved partial representations. Primary BROWN1966, original pp326–328 read before code; see source_audit.md. No manipulated cue arms. Twelve original Chinese definition items are item conditions, not12 experimental groups. Outcomes: reported TOT, intended-target-confirmed TOT, exact spontaneous resolution, reported resolution latency, pre-resolution initial-sound/character-count accuracy. No clinical/normative inference.

## 2. Block/Trial Workflow
One block,12 unique labels, even/default weights(null), built-in BlockUnit.generate_conditions; seed130031 same across subjects. No custom generation, no in-trial randomness. Trial IDs from next_trial_id.
States: ready(space,self-paced) -> fixation(0.5s) -> judgment(definition;1 know,2 TOT,3 don't know;20s). Missing judgment remains missing and is never inferred as don't-know. Know -> known_answer(blank text,F2 submit,15s). TOT -> initial_sound(blank pinyin initial text,10s) -> character_count(keys1–4,0 unknown,8s) -> related_words(blank text for similar sounds/meanings,10s) -> resolution(blank target entry,F2 submit,15s). During each partial phase F4 means the whole word has spontaneously returned: stop partial collection and go directly to resolution. Don't-know/missing -> verification. All paths -> verification(revealed intended target;1 sought/known,2 different,3 unfamiliar/unsure;10s) -> saved(0.5s). A different-target claim additionally retains an optional alternative_target text(10s); alternatives require independent linguistic coding, not automatic intended-target confirmation.
No answer or correctness hint is shown before resolution ends. Partial reports after F4 are excluded; timed-out partial text is saved but not counted as submitted. Enter is only an editor/IME event. F2 is deliberately separate from text entry. StimUnit public get_state and high-resolution flip_time support branches/timestamps. Definition and prompts persist during active response phases.

## 3. Condition Semantics
tot01–tot12 each denotes one newly authored definition with specified intended/accepted forms, target initial sound and character count in config. The full concrete item inventory and all phase content are mapped in stimulus_mapping.md. Words cover2–4 characters. These are candidate uncommon familiar terms, not frequency-normed items. No target text appears until verification. Config owns all participant copy; SimHei Chinese font. Defined items are constant, so realization is lookup only.

## 4. Response and Scoring Rules
Keys and durations from config. Judgment1=know,2=TOT,3=don't-know; absent=missing. F2 submits a typed response, F4 marks spontaneous retrieval during partial phases. Only submitted normalized accepted strings are objectively correct. No fuzzy synonym acceptance. All raw text retained for independent adjudication. Reported TOT means judgment2. Confirmed intended-target TOT means reported TOT AND (correct pre-reveal typed resolution OR verification1). Keep confirmation_basis=typed/recognition/both/none. False/different and unverified TOT remain distinct. Recognition affirmation is subjective, susceptible to demand effects; never conflate it with typed proof. Original positive-TOT alternative-effective-target analysis is not automatically reproduced.
Initial-sound accuracy compares submitted lowercased pinyin initial with target; count accuracy compares1–4. Unknown0/missing/unsubmitted not incorrect; accuracy denominator only submitted usable guesses within confirmed intended-target TOT. F4 phase data are not counted because resolution may already have occurred. Spontaneous resolution requires reported TOT plus correct submitted pre-reveal target. Resolution latency starts at judgment response (high-resolution flip_time+rt) and ends at earliest F4 response, otherwise correct resolution submission; includes intervening partial-report activity and typing, not a pure covert access time. Clock is software monotonic, not hardware-calibrated. No reward/controller.

## 7. Architecture Decisions (Auditability)
Simple mode-aware main and thin run_trial; PsyFlow owns scheduling, trial IDs, event capture and phase persistence. utils handles pure target normalization/scoring and descriptive summaries only. No controller or legacy compatibility. Native editor rebuilt blank every entry using PsyFlow43e52fb Unicode adapter. Synthetic text is allowed only in declared QA/sim fixtures, never human config; semantic branch test separately exercises actual run_trial.

## 8. Inference Log
Original oral group English procedure becomes individual visual Chinese.12 original items, one block,20/15/10/8s windows,keys,repeatable seed and per-item ready rest are inferred usability choices. English first letters/syllables replaced with Mandarin pinyin initial and Chinese character count; related words retained but not automatically phonologically coded. Optional alternative target retained for manual coding. Strict intended-target confirmation differs from source positive-TOT definition. No materials pilot, norms, reliability or clinical validity established. Typing/orthographic and IME skills may affect responses; dialectal pronunciations and synonyms need pilot/adjudication. Native backend Unicode tests do not establish actual OS IME behavior.

Mandarin scoring inventory: b p m f d t n l g k h j q x zh ch sh r z c s and0(zero consonant onset). zh/ch/sh are indivisible. y/w are pinyin spelling carriers, not scored as consonant initials. Current targets all have consonant onsets. Accepted traditional variants preserve pronunciation and character counts. Invalid inputs are retained and excluded from usable-guess denominator.
